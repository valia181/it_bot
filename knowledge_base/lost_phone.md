# Втрата корпоративного телефону

Інструкція щодо дій співробітника у разі втрати або викрадення службового мобільного пристрою (смартфона чи планшета).

## Термінові першочергові дії

1. **Негайне повідомлення ІТ-підтримки:**
   - Якнайшвидше повідомте чергового інженера ІТ через гарячу лінію або через колегу.
   - Спеціаліст служби підтримки дистанційно ініціює блокування пристрою через систему керування мобільними пристроями (MDM) та запустить процедуру повного видалення корпоративних даних (remote wipe).

2. **Блокування корпоративної SIM-картки:**
   - Зверніться до координатора корпоративного мобільного зв'язку або зателефонуйте на лінію підтримки оператора зв'язку для негайного блокування SIM-картки та запобігання несанкціонованим дзвінкам і SMS.

3. **Скидання корпоративних сесій:**
   - Служба безпеки та системні адміністратори виконають примусове завершення всіх активних сеансів у пошті, месенджерах і корпоративних сховищах.
   - При першій нагоді змініть пароль свого корпоративного облікового запису з безпечного робочого комп'ютера.

4. **Повідомлення керівництва:**
   - Проінформуйте безпосереднього керівника про факт втрати робочого телефону та орієнтовні обставини інциденту.

5. **Отримання тимчасового або нового пристрою:**
   - Оформіть заявку у внутрішній системі заявок на отримання резервного телефону для забезпечення безперервності робочих процесів.
