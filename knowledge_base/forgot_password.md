# Відновлення забутого пароля корпоративного облікового запису

Інструкція для співробітників щодо відновлення доступу до облікового запису при втраті чи забутті пароля.

## Процедура відновлення доступу

1. **Самостійне відновлення через портал:**
   - Перейдіть у веб-браузері на сторінку порталу самообслуговування: `https://id.corp.local/recovery`.
   - Введіть вашу повну корпоративну електронну адресу.
   - Підтвердьте запит за допомогою коду або сповіщення у корпоративному додатку двофакторної автентифікації (2FA).

2. **Вимоги до нового пароля:**
   - Мінімальна довжина пароля становить не менше 12 символів.
   - Пароль повинен обов'язково містити великі та малі літери латинського алфавіту, цифри та спеціальні знаки.
   - Заборонено використовувати раніше вживані паролі або прості комбінації.

3. **Якщо доступ до 2FA втрачено або самостійне скидання не працює:**
   - Зверніться до свого безпосереднього керівника для підтвердження вашої особи.
   - Керівник подасть підтверджений запит до служби підтримки для скидання доступу та генерації первинного одноразового ключа входу.

## Правила безпеки

- Співробітники ІТ-підтримки ніколи не запитують ваш діючий пароль телефоном, у месенджерах чи електронною поштою.
- Ніколи не повідомляйте свій пароль колегам та не записуйте його на паперових носіях біля робочого місця.
